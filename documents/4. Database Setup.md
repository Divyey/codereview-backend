Essential Tables for Your Platform

    users
    Stores user accounts, authentication, and profile info.

    repositories
    Git repositories being analyzed.

    pull_requests
    Each code PR, with metadata and status.

    pr_files
    Files changed in a PR, with diff/patch info.

    pull_request_analysis_history
    Stores each AI analysis run for a PR (for history/auditing).

    code_quality_issues
    All code quality findings (docstring, complexity, anti-patterns, dead code, duplicates, etc.).

    security_findings
    Security, secrets, infra, and SCA findings.

    pr_comments
    Comments, questions, and answers on PRs (AI or human).

    pull_request_reviews
    Human or AI review actions/approvals.
